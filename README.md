# Igreja Ortodoxa Grega G.O.C. no Brasil

Portal de fé, formação, história e missão da Igreja Ortodoxa Grega G.O.C. no Brasil, inspirado na identidade visual e na estrutura de [gregagog.lovable.app](https://gregagog.lovable.app/).

## Como executar

```bash
npm install
npm run dev
```

O site abre em `http://localhost:5173`.

## Páginas

- Home, fé, liturgia, santos, calendário e formação em 9 passos
- Igreja, mosteiro, paróquias, santo sínodo e missões
- Hierarquia e perfis do clero
- Pedidos de oração, pesquisa, enciclopédia, notícias, vídeos e biblioteca
